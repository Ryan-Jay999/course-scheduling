# 排课选课与教务协作系统（Demo）

面向中小学/职业院校教务场景的「排课—选课—冲突处理」协作系统 Demo。核心主张：**排课不是瓶颈，协作断点才是**——把冲突提示从「选中后」提前到「选中前」，把 AI 处理不了的场景强制转人工并全程留痕。

> 基于知行职业学院 FDE 需求发现报告（36 条事实，f00–f55）与行业分析报告构建，每条业务规则均可溯源到事实编号。

## ✨ Demo 核心能力

- **选中前冲突拦截**（REQ-1）：先修/时间/场地三类冲突在学生点「选课」前实时提示，标注数据同步时间，不承诺实时
- **冲突处理工作流**：AI 建议 → 四类场景强制转人工（留痕：触发原因/接手人/确认时间）→ 交接五要素 → 签核闭环
- **AI 教务助手（RAG）**：基于知识图谱的问答，回答强制携带 `[f##]` 事实引用与「建议，非决定」标签
- **知识图谱**：60 实体 / 97 三元组 / 36 事实锚点，9 类实体着色，可拖拽、筛选、溯源
- **快照降级演练**：一键模拟接口中断 → 快照兜底「暂未更新」→ 重连去重补齐
- **审计追溯**：处理链路时间线重建（AI 步/人工步分色），字段落库方式核查

## 🚀 运行方式

## 🧠 知识图谱构建方法（LLM Wiki + RAG）

```
访谈记录(36条事实) / 行业报告 ──► LLM 三元组抽取 ──► Wiki 与行业数据补充
        ──► 人工校核入库 ──► 图存储(Neo4j) + 向量化(pgvector) ──► RAG 检索服务
```

- 每条三元组强制携带事实锚点（`f00`–`f55`），可溯源、可审计
- 检索链路：查询改写 → 实体链接 → 子图扩展 + 向量召回 → 重排 → 受约束生成（带引用）
- 兜底：低置信/歧义不自动生成，转人工修复队列
